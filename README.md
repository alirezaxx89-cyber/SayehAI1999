# سایه — نسخه نهایی شخصی 3.0

این نسخه برای استفاده شخصی ساخته شده و شامل چت، حافظه محلی، انتخاب/تحلیل عکس، ساخت تصویر، گفتار به متن، خواندن پاسخ با TTS و رابط تاریک است.

## ساخت APK فقط با گوشی

برای اینکه لازم نباشد Android Studio نصب کنی، پروژه یک GitHub Actions آماده دارد. از مرورگر گوشی:

1. یک مخزن جدید در GitHub بساز.
2. فایل‌های این پروژه را داخل مخزن قرار بده و روی شاخه `main` بفرست.
3. وارد تب **Actions** شو.
4. گردش کار **Build Sayeh APK** را اجرا کن (Run workflow).
5. بعد از اتمام، از همان اجرای موفق، بخش **Artifacts** فایل `Sayeh-debug-apk` را دانلود کن.
6. فایل APK را روی گوشی نصب کن. اگر اندروید اجازه خواست، نصب از همان منبع را فعال کن.

## وارد کردن کلید بعد از نصب

دیگر لازم نیست کلید را قبل از ساخت APK وارد کنی. داخل خود برنامه دکمه **🔑 کلید** را بزن و کلید OpenAI خودت را وارد کن. کلید در حافظه خصوصی برنامه ذخیره می‌شود.

**کلید را در چت، GitHub، یا فایل عمومی منتشر نکن.**

## نکته

این روش برای استفاده شخصی مناسب است. چون کلید روی دستگاه ذخیره می‌شود، APK را با دیگران به اشتراک نگذار. برای انتشار عمومی باید کلید پشت یک backend امن قرار بگیرد.
